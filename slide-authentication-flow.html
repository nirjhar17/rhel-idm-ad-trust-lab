1. SSH

User connects with AD credentials (john.l1@ad.demo.local)

2. PAM

Pluggable Authentication Modules handle auth via pam_sss module

3. SSSD

Connects to IDM, caches credentials locally for offline access

4. IDM → AD

IDM validates via Kerberos trust, AD confirms identity

Key Insight

No direct connection between Linux server and AD. SSSD always goes through IDM, which controls access (HBAC + Sudo) even though AD authenticates identity.
