The Authentication Chain

Step Component What It Does
1 SSH User connects with AD credentials (john.l1@ad.demo.local)
2 PAM Pluggable Authentication Modules handle auth request
3 pam_sss PAM module that bridges to SSSD
4 SSSD Connects to IDM, caches credentials locally
5 IDM Validates via Kerberos cross-realm trust
6 AD Confirms user identity and password

✓ Key Insight

No direct connection between Linux server and AD. SSSD always goes through IDM, which controls access (HBAC + Sudo) even though AD authenticates identity.
