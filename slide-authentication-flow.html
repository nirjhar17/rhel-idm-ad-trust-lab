Authentication

How AD Users Login to Linux Servers

The Authentication Chain

1 SSH User connects with AD credentials
2 PAM Handles authentication request
3 pam_sss PAM module bridges to SSSD
4 SSSD Connects to IDM, caches credentials
5 IDM Validates via Kerberos trust
6 AD Confirms user identity

Key Insight

No direct connection between Linux server and AD. SSSD always goes through IDM, which controls access (HBAC + Sudo) even though AD authenticates identity.
