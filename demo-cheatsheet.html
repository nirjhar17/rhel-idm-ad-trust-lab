DEMO 6: High Availability (Optional - 5 min)
SSH as L1 (John) first → Password: Demo@2026!

✗ DENIED - L1 cannot check IDM server status
sudo sssctl domain-status idm.demo.local

✓ ALLOWED - Only L3 can check system status

Should show: Active servers: IPA: idm.idm.demo.local (primary)

ssh azureuser@172.190.242.84

exit
Now login as AD user (still works via replica!) → Password: Demo@2026!

Say: "Primary is down, but login still works because SSSD fails over to replica"

exit && ssh jane.l2@ad.demo.local@20.51.158.128
Check which server is now active (Jane can do this)

Should now show: Active servers: IPA: idm2.idm.demo.local (replica!) - Failover worked!
