What Can AD Users Do on Linux?

Authentication = "Who are you?" (AD) → Authorization = "What can you do?" (IDM)

HBAC: Which Servers Can You Access?

Host-Based Access Control determines which servers a user can log into.

User Group
Allowed Servers
L1 Operators

L2 Admins

L3 Super Admins

Sudo Rules: What Commands Can You Run?

Sudo rules control which commands a user can execute with elevated privileges.

User Group
Allowed Commands
L1 Operators

Key Insight

AD verifies WHO you are. IDM controls WHAT you can do.

This separation means: AD team manages users (hire/fire), Linux team manages access policies (security). Clean separation of duties for RBI compliance.
