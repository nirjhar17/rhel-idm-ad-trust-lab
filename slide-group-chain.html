Why This Chain?

  • External Groups can only reference AD objects (by SID)
  • POSIX Groups have GIDs needed for Linux permissions
  • HBAC/Sudo rules only work with POSIX Groups
  • Chain bridges Windows SIDs to Linux GIDs

Key Benefit

When AD admin adds user to Linux_L1_Team in AD, that user automatically gets L1 access on all Linux servers. No IDM changes needed.
